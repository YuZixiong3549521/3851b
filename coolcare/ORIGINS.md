# Source provenance

CoolCare combines the team's uploaded customer, technician, inventory and AC Care website projects. Their maintained React components, technician source, runtime assets and MySQL schema now live in this `coolcare/` directory.

The original uploads were previously tracked as `CoolCare_Customer_App/`, `aircon-technician-portal/`, `CoolCare_Website_20260908_150040/`, `accare/` and `accare.zip`. They are no longer part of the current Git checkout or required by setup. Copies on the repository owner's machine remain ignored local references, and earlier Git commits retain the original tracked files.

The uploaded `accare/backend/package.json` declared its package license as ISC. No separate LICENSE or copyright notice was supplied with that upload. This record preserves the declared source metadata; it does not assign a license to the combined application or change any dependency's license. Third-party package licenses remain distributed with their respective packages and lockfile-resolved dependencies.

The optional SQLite importer accepts an explicit local source path. Historical customer data and password hashes are not distributed as an application dependency.
