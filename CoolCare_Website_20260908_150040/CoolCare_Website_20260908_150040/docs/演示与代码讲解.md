# 3–5 分钟演示流程

## 开场

“我把 Stitch 中的六个库存原型页面做成了真实网页，前端用 React，后端用 Node.js 和 Express，数据库用 MySQL。目前只实现 Admin Inventory。”

## 演示

1. 登录后展示 Overview：库存金额、零件总数、低库存提醒和最近流水均来自 MySQL。
2. 打开 Parts：搜索 Aircon Filter，展示筛选与详情跳转。
3. 添加一个未使用过名称的 Demo 零件，单价填 10.00，状态 Active；说明库存初始为 0。
4. Stock In 10 件，确认后库存为 10。
5. Stock Out 3 件，确认后库存为 7。
6. 展示 Transactions 中的入库和出库记录，以及操作管理员。
7. 刷新页面，说明库存仍是 7，数据不是只存在浏览器中。
8. 可尝试出库 8 件，展示负库存保护。不要为了演示改动原有的三个零件。

## 展示代码

前端入口：`web/components/inventory-app.tsx`。展示侧边栏、登录和路由状态。

页面功能：`web/components/inventory-views.tsx`。展示零件表单和出入库确认框。

后端入口：`web/server/index.mjs`。说明 Node.js 使用专用数据库账号连接 MySQL，而不是让浏览器直接连接数据库。

接口层：`web/server/app.mjs`。说明请求需要管理员登录，并且在服务器校验输入。

库存业务：`web/server/inventory.mjs`。说明数据库事务把库存修改、流水记录放在一起；失败回滚；重复请求不会重复扣库存。

数据库结构：`database/schema.sql`。重点讲 `part`、`inventory_transaction` 两张表。网页新增的 `inventory_web_operation` 表记录操作前后数量、调整方向对应的增减值和重复请求标识；定义可在 `web/scripts/prepare-local.mjs` 查看。
