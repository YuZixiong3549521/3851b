# CoolCare 网页展示包

这是 React + Node.js + MySQL 库存管理网页的源码与展示资料包。

## 解压到桌面后怎么展示

1. 右键 ZIP，选择「全部解压」，不要在压缩包内直接运行脚本。
2. 双击 `01_启动现有网页.cmd`。
3. 如果打开了运行窗口，请保持打开，等待出现 `http://localhost:3000/`。
4. 用 Chrome 或 Edge 打开 <http://localhost:3000/admin/inventory>。
5. 网页演示邮箱：`norshida@coolcare.demo`；密码：`CoolCareDemo2026!`。这不是 MySQL root 密码。

**本机快捷入口使用你原来的已配置项目。请保留原项目文件夹和 MySQL，不要删除它们。** 这个入口是本机专用的，不是给其他电脑用的安装程序。如果网页已在运行，入口只会提示现有服务可用。

## 包里有什么

- `web/`：全部网页业务源码、共享界面组件、配置模板、依赖锁文件、测试和启动脚本。
- `database/`：原有数据库结构、演示数据、验证 SQL，以及打包时的库存数据 JSON 快照。
- `prototype/`：原型参考图、ER 图、原型提示词和 Stitch 链接。
- `docs/`：演示讲解稿、代码讲解与独立运行说明。
- `MANIFEST.sha256`：用于核对包内文件完整性的校验清单。

## 看代码时打开哪些文件

用代码编辑器打开整个 `web` 文件夹。主要文件如下：

| 内容 | 文件 |
| --- | --- |
| 总体布局、导航、登录界面 | `web/components/inventory-app.tsx` |
| 六页库存界面与表单 | `web/components/inventory-views.tsx` |
| 共享界面控件 | `web/components/inventory-ui.tsx` |
| 页面样式 | `web/app/globals.css` |
| 前端请求、类型与共享状态 | `web/lib/inventory-client.tsx` |
| Node.js 接口、登录与权限 | `web/server/app.mjs` |
| 数据库事务、库存校验和重复提交保护 | `web/server/inventory.mjs` |
| 数据库表结构 | `database/schema.sql` |

## 安全与运行限制

ZIP 故意不包含本机 `.env.local`、含密码的 `.local` 文件夹、`node_modules`、编译缓存或日志。解压出来的源码不是免安装离线程序；要独立启动这一份源码，请看 `docs/独立运行说明.md`。

MySQL 数据保存在数据库服务中，并不会随网页文件夹移动。`inventory-snapshot.json` 只备份库存相关数据，不是整个数据库的 SQL 恢复文件。`seed.sql` 是原有演示数据，不代表打包时的最新数据。

**已有数据库不要重复运行 `schema.sql` 和 `seed.sql`。** 演示新增、编辑或出入库会真正改变数据库。建议使用专门的 Demo 零件。

本网页目前只用于本机演示和开发，没有公网部署。不要把演示账号用于生产环境。
